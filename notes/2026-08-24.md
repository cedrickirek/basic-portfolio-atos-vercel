```
src/hooks/                  useReducedMotionSafe.ts
public/carousel/            7 processed WebP slides
public/docs/                two theses + CV
```

Content lives in `src/data/` so entries change without touching components.

### Things that will bite you

- **`motion/react-client` vs `motion/react`.** Client components must import
  `{ motion } from "motion/react"`. Using the `react-client` entry inside a
  `"use client"` file makes `whileInView` silently never fire — the timelines
  rendered invisible at `opacity: 0` and the build passed clean.
- **`useReducedMotion` has no SSR snapshot.** It returns `false` on the server
  and the real value on the client, so any markup branching on it hydrates with
  a mismatch. `src/hooks/useReducedMotionSafe.ts` wraps it in
  `useSyncExternalStore` with an explicit server snapshot. Do not go back to
  `useEffect` + `setState` — React 19's lint rejects it as cascading renders.
- **`tsc --noEmit` alone errors on `LayoutProps`** before a build has run. It
  is a Next 16 generated type; run `npm run build` first, then typecheck.
- **Playwright `fullPage: true` does not trigger `whileInView`.** Scroll the
  page in `page.evaluate` before screenshotting, or every scroll-revealed
  section captures blank. This caused a false "the timelines are broken" report.
- **Static export disables `next/image` optimisation** — `images.unoptimized`
  is set in `next.config.ts`. Images must be pre-processed; `sharp` was used at
  1200×1500 WebP. Three source photos had EXIF orientation 6 and needed
  `.rotate()` or they render sideways.
