## Things that will bite the next session

- **`npx tsc --noEmit` is not optional.** Cedric declared `country` as
  required while four `journey` entries lacked it: **four type errors that
  the dev server served straight past**, because Turbopack does not
  type-check. Run it before every commit. He asked what the command means and
  now knows — expect him to run it himself.
- **`tsc` cannot see the filesystem.** A `thumbnail` path is a valid string
  whether or not the file exists. That is exactly how `linkedin.webp` sat
  broken. **For the three images next session, the browser is the check** —
  fetch each path and confirm a 200.
- **The previous handoff note was wrong about pushing.** It said neither
  design branch was pushed; both were already on the remote and tracking.
  Verify with `git branch -vv` rather than trusting a note.
- **Commit messages: `@'...'@` is PowerShell syntax and leaks a literal `@`
  as the first line under Bash.** It happened this session and needed an
  amend before pushing. Use `git commit -F <file>` instead.
- **Long Bash heredocs break on apostrophes and get truncated.** Writing this
  very note failed that way first. Use the Write tool for prose files.
- **A dev server from the *previous* session was still alive on :3007** and
  blocked `npm run dev` from starting. It is still running (PID 56692).
  `taskkill /PID 56692 /F` if it needs restarting; otherwise reuse it.
- Carried forward: `motion/react` not `motion/react-client` in client
  components; `next lint` does not exist in Next 16, use `npx eslint src/`.
