### `c791845` then `275d19a` — the card hover, fixed twice

Worth reading because the first fix was wrong and the reasoning matters.

Cédric reported adjacent cards growing and shrinking as the pointer moved
along a row. **No card was ever scaling** — the only transform is on the
thumbnail. What moved was the description: hover swapped `line-clamp-2` for
`line-clamp-none`, the card grew, and a grid row stretches every card to a
common height, so one card growing re-flowed all of them. Measured: +88px on
case 001, +44px on case 002, a step change at every crossing.

First attempt floated the full text over the card. That fixed the row but
**covered the tags** — which Cédric then reported. Moving the panel around
did not help: the full text needs ~266px and the largest free region in a
card is the 180px thumbnail. There is no placement that hides nothing.

Final answer: the card never expands. Three lines always, hover only lifts
the border and zooms the thumbnail, full text is a click. Truncating alone
was not an option either — three lines covers 51–100% of these
descriptions depending on the project.

**Lesson for next session: measure the space before designing into it.** Two
commits were spent discovering the text did not fit.

### `2e8bbc7` — first Lighthouse run, and what it found

Ran against the built output, not the dev server. **Home and /projects:

question, not a tweak — and **adding video will make it worse**, so measuring
it again before the reels land is meaningless. The cahier puts it out of
scope for this reason.

## Things that will bite next session

- **`generateStaticParams` is mandatory for `/projects/[slug]`.** Read in
  `node_modules/next/dist/docs/` this session, not from memory: under
  `output: "export"` a dynamic route needs `generateStaticParams()` **and**
  `dynamicParams: false`, or the build fails. And **`params` is now a Promise
  that must be awaited** — the old synchronous signature does not compile.
  This is Chantier B and it will be the first thing to get wrong.
- **A type is not a renderer.** `reel`, `slides` and `caseStudy` all exist on
  the type and draw nothing until a component reads them. Already happened
  once with `country` on the timeline.
- **Headless Chrome's `--window-size` does not set the layout viewport.** The
  page renders wide and gets cropped, which looks exactly like horizontal
  overflow. Load the page in a 390px `<iframe>` instead. Cost about twenty
  minutes this session before it was recognised.
- **A click below the fold never lands.** When driving CDP, scroll the target
  into view in its own round trip and let it settle before reading the rect —
  doing both in one expression returns the pre-scroll position.
- Carried forward: `git commit -F <file>` (PowerShell's `@'...'@` leaks a
  literal `@` under Bash); `npx eslint src/` not `next lint`; long Bash
  heredocs mangle backslashes, use the Write tool for scripts with regexes.
